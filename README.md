# Student To-Do List Manager

A responsive beginner-friendly task manager made with HTML, CSS, and JavaScript.

## Features
- Add tasks and optional due dates
- Edit and delete tasks
- Mark tasks as completed
- Filter all, active, and completed tasks
- Save tasks in browser local storage
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in your browser.

## Publish on GitHub Pages
1. Push these files to your `todo-list-manager` repository.
2. Open **Settings → Pages**.
3. Under the build/deployment settings, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

Tasks are saved only in the current browser, not synced between devices.
